# Official D&D 5th Edition books (checklist)

Every official Wizards of the Coast 5e book, 2014 rules and 2024 revision, as of October 2026.
Tick each one once its PDF is in your `DND books` folder. The app only reads PDFs (not EPUBs),
and Q&A cites a book by its file name, so name each file after the book (e.g. `Player's Handbook (2024).pdf`).

Not included: third-party books, free promo PDFs (Plane Shift, Elemental Evil Player's Companion),
D&D Adventurers League modules, cookbooks, Young Adventurer's Guides and lore art books.
